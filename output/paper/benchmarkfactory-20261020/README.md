# BenchmarkFactory 研究论文

本文围绕韧性测试智能体的风险发现与场景设计、故障执行与扰动应对、根因诊断及修复验证，给出机制驱动的基准构建方法、两种评测模式、指标体系和实验设计。

实验设计包含模型与原生智能体双轨对比、开发集与隐藏测试集划分、预算冻结、重复运行、扰动配对及统计分析。结果表中的实验数据保持空白。
